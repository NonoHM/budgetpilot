# Logging screenshots

Naming and sizes follow [the screenshots convention](../README.md): `<state>-<viewport>.png`, desktop
at 1920 x 1080. Neither image has a mobile file, because neither page is meant to be read on a phone
in a way that differs.

| Image                                                          | Page that embeds it                                        | What it shows                                                                                        |
| -------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [`error-reference-desktop.png`](./error-reference-desktop.png) | [The tutorial](../../logging-tutorial.md)                  | The error page of a failed Net worth request, with its reference                                     |
| [`grafana-explore-desktop.png`](./grafana-explore-desktop.png) | [Send the log to a collector](../../logging-collectors.md) | Grafana Explore running the LogQL query for one error reference on Loki, and the one line it returns |

Neither image is generated by `scripts/doc-screenshots.mjs`. Each is a throwaway capture made by the
steps below, and the data in both is synthetic: one account, `paul.mercier@example.test` (holder Paul
Mercier, who does not exist), no transactions. No address, name or path of the machine appears in
either. Look at each image before committing a new one: the private-reference scanner reads text, not
pixels.

## `error-reference-desktop.png`

1. Start an instance on an empty volume, as in [the tutorial](../../logging-tutorial.md), with the
   English language (the browser sends `en-US`).
1. Register the first account at `/register` with the bootstrap token from `.env`.
1. Rename the table the Net worth page reads, with the command in tutorial step 5, so that the page
   fails.
1. Open `/net-worth` in headless Chromium at 1920 x 1080, signed in, and take a full screenshot with
   Playwright:

   ```js
   const { chromium } = require('playwright');
   const browser = await chromium.launch();
   const context = await browser.newContext({
   	storageState: 'state.json', // the session saved after registering
   	locale: 'en-US',
   	viewport: { width: 1920, height: 1080 }
   });
   const page = await context.newPage();
   await page.goto('http://localhost:3000/net-worth');
   await page.screenshot({ path: 'error-reference-desktop.png' });
   await browser.close();
   ```

1. Rename the table back with the command in tutorial step 6.

The reference on the page changes on every capture. The alt text in the tutorial does not quote it.

## `grafana-explore-desktop.png`

1. Run the Alloy, Loki and Grafana recipe in [Send the log to a collector](../../logging-collectors.md),
   with an error reference from a failed request (the capture above produces one).
1. Open Grafana Explore at 1920 x 1080 with the query for that reference, in a URL, and take the
   screenshot once the line has rendered:

   ```js
   const panes = {
   	a: {
   		datasource: 'loki',
   		queries: [
   			{
   				refId: 'A',
   				expr: `{service_name="budgetpilot"} | error_id="${reference}"`,
   				queryType: 'range'
   			}
   		],
   		range: { from: 'now-3h', to: 'now' }
   	}
   };
   await page.goto(
   	`http://localhost:3001/explore?schemaVersion=1&orgId=1&panes=${encodeURIComponent(JSON.stringify(panes))}`
   );
   await page.getByText('budgetpilot.request.failed').first().waitFor();
   await page.screenshot({ path: 'grafana-explore-desktop.png' });
   ```

The image shows the Grafana interface of the version pinned in the recipe, and the name of the test
container in the small `container=` label above the result. It ages with Grafana's interface: retake
it when the pinned version changes.
