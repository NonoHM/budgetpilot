# Admin screenshots

against a running instance in English.

The instance is seeded through the real routes so the page has something to
show: a second account created from an invitation, and a third invitation
left pending so the list is not photographed in its empty state.

`users-desktop.png` is the whole page, which is why it also carries the
Invitations section; `invitations-desktop.png` frames that section alone.
